## Reference hierarchy for the POC

Use the official PAS for its provisions; the selected TIC4.0 dictionary/model publication for domain meaning and representation; and a versioned vendor specification for source-field meaning. Record unresolved conflicts rather than silently combining inconsistent examples.

A release title or mutable web page does not by itself identify the exact machine-readable artifact used. Repository copies should preserve publisher notices and record permitted use.
